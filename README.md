# 黄白 Video Editor

把过审素材导入剪映，完成分轨、换镜、字幕、花字、蒙版和实际导出复查。

- 查看 [SKILL.md](SKILL.md)。
- 在 Codex 使用时，将仓库下载并解压，把包含 `SKILL.md` 的文件夹命名为 `huangbai-video-editor`，复制到 `~/.codex/skills/`。重新开启对话后调用 `$huangbai-video-editor`。
- 涉及剪映、录屏或媒体命令行工具时，按实际安装的应用和接口验证。
