# 剪辑与导出复检

先查看实际由编辑器导出的文件。对比当前时间线和同版准用素材，检查修改段、前后切口和调整时长影响到的后续轨。先看画面与原声是否成立，再确认文件规格和交付位置。

- 批量替换画面、小窗、字幕样式前后，可比较两版导出音轨和总时长。该结果证明音频一致或差异位置；语义与视听连贯仍要把前后句连起来检查。
- 快速导出检查片可以确认画面、时序、单行与遮挡。正式分辨率的清晰度、求精细的字形和抠像边缘按最终输出实际检查。
- 受影响镜头优先查首尾和中间动作。进入上一句、目标变化和下一句都看得到，发现跳帧、叠脸、黑屏、漏字或遮挡就返回对应轨修订，重新导出复查。
- 项目要求独立复检时，由未制作该段的检查者查看实际导出。共享的[复检准备、抽帧、视觉检查和记录方式](https://github.com/huangbai-AI/huangbai-broll-maker/blob/main/references/post-render-review.md)适用于成片复检。使用该参考里的脚本时，脚本和默认构图配置位于黄白 Broll Maker，横竖屏与安全区按本项目提供。
- 分开记录单条素材、剪辑工程、导出和审片工作台各自的版本与检查状态。工作台更新后回看播放源、镜头跳转和批注定位。
